# Pre-Deployment Checklist

## Content
- [ ] Update company name and details in HTML
- [ ] Update privacy policy in `privacy.html`
- [ ] Update contact information (email, phone, address)
- [ ] Add real images to `images/` folder
- [ ] Add font files to `fonts/` folder

## Configuration
- [ ] Update Google Analytics ID in `js/cookies.js`
- [ ] Configure contact form backend
- [ ] Update favicon if needed
- [ ] Update meta descriptions in HTML head
- [ ] Configure custom domain (if applicable)

## Testing
- [ ] Test on Chrome, Firefox, Safari, Edge
- [ ] Test on iPhone/iPad
- [ ] Test on Android devices
- [ ] Test form validation
- [ ] Test cookie banner
- [ ] Test all links
- [ ] Test navigation scroll effect
- [ ] Check page load speed

## Performance
- [ ] Optimize images (compress with TinyPNG)
- [ ] Minify CSS (optional, already minimal)
- [ ] Test Core Web Vitals
- [ ] Enable GZIP compression on server
- [ ] Set up CDN (if available)

## Security
- [ ] Enable HTTPS/SSL
- [ ] Add security headers
- [ ] Update robots.txt with sitemap
- [ ] Set up email validation for forms
- [ ] Review data privacy policies

## SEO
- [ ] Update page titles
- [ ] Update meta descriptions
- [ ] Add keywords to content
- [ ] Verify sitemap.xml
- [ ] Submit to Google Search Console
- [ ] Submit to Bing Webmaster Tools
- [ ] Add Open Graph tags

## Go Live
- [ ] Final QA review
- [ ] Check all forms work
- [ ] Verify analytics tracking
- [ ] Document deployment steps
- [ ] Set up monitoring/alerts
- [ ] Create rollback plan

## Post-Launch
- [ ] Monitor analytics for issues
- [ ] Check error logs daily
- [ ] Set up automated backups
- [ ] Plan content updates
- [ ] Gather user feedback
